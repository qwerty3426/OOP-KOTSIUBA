# IndependentWork24

## Тема
Інтеграція структурних патернів + тести

## Використані патерни

### Composite
- TaskItem
- ProjectTask

### Decorator
- PriorityDecorator
- LoggingDecorator

### Proxy
- TaskProxy (кешування виконання)

---

## Що перевірено тестами

- Робота Composite (сума підзадач)
- Робота Decorator (додавання поведінки)
- Робота Proxy (кешування результатів)
- Граничний випадок (порожній проект)

---

## Продуктивність / компроміси

- Proxy зменшує повторні обчислення (кеш)
- Decorator додає невеликий overhead через обгортки
- Composite збільшує витрати при глибокій ієрархії

---

## Висновки

- Комбінація патернів дозволяє будувати гнучку архітектуру
- Proxy значно покращує продуктивність при повторних викликах
- Decorator дає розширення без зміни коду
